安装 · 更新 · 卸载

安装 · Linux 
curl -fsS https://agent.noxcaw.com/install | bash

装到 ~/.caw-agent/bin，并写入 shell PATH。当前终端请 source ~/.caw-agent/env，或新开一个。

更新 
caw-agent upgrade now

只检查、不下载用 caw-agent upgrade。指定版本：caw-agent upgrade v0.1.8。

卸载 · Linux 
rm -rf ~/.caw-agent

会删掉二进制、配置、密钥和 MCP。shell rc 里 # >>> caw-agent >>> 到 # <<< caw-agent <<< 那几行请手动删。

为什么用它

动手干活

它在你的项目里读代码、改文件、跑测试。不只是聊天，是真正干活的搭档。

安全可控

它只访问你打开的这个目录。每次写盘、每条命令，都会先停下来征求你的同意。

过程透明

读、改、跑，每一步都实时显示在眼前。想介入或叫停，随时都可以。
