terminal coding agent

在沙箱里写代码，
权限问过再动手。

Claude Code 风格的 TUI：文件 jail、exec OS 沙箱、MCP、会话记忆，以及从 GitHub Release 自更新。 预编译包装到 ~/.caw-agent/bin。

按平台选包

指定版本

/upgrade v0.1.1 或安装脚本传入标签。空的 /upgrade 只检查，不下载。

无头模式

caw-agent --print -w . "…" 适合 CI。权限 / 提问 / 计划可用 --on-* 自动回答。
